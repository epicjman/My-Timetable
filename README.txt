MY TIMETABLE — iPHONE HOME SCREEN APP

This is a small installable web app (PWA) version of your timetable.

IMPORTANT: Safari requires the files to be hosted on an HTTPS website before Add to Home Screen and offline installation will work. Opening index.html directly from Files is not enough.

EASIEST PUBLISHING METHOD (GitHub Pages):
1. On a computer, create a GitHub account if needed and create a new repository.
2. Upload every file in this folder to the repository's main/root folder.
3. In the repository, open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
5. Wait for GitHub Pages to give you a website address.
6. Open that address in Safari on your iPhone.
7. Tap Share (square with arrow) > Add to Home Screen > Add.

You can also use another HTTPS static hosting service. Keep the folder files together.

The timetable saves in Safari's local storage on that iPhone. It is not automatically synced with your PC. Use the timetable's backup export/import if you want to transfer your timetable. After the first successful load, the app can work offline. Do not clear Safari website data if you want to keep its saved timetable.
